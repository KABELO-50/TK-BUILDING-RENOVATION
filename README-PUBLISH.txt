TK BUILDING & RENOVATION — NETLIFY PUBLISH PACKAGE

1. Sign in to Netlify.
2. Open Sites, then choose “Add new site” > “Deploy manually”.
3. Drag and drop this ZIP file, or drag the unzipped folder.
4. After deployment, open the generated Netlify address and test:
   - Home, About, Services, Gallery, Leadership and Contact
   - Mobile menu
   - WhatsApp buttons
   - Quote request form
   - Google Maps
5. To use www.tkbuildingandrenovation.co.za, add it under Domain management.
6. Replace the website URL in sitemap.xml if you use a different permanent domain.

The quotation form opens WhatsApp and does not require a server.
